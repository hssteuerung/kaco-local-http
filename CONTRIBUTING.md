# Mitwirken

Vielen Dank für dein Interesse an KACO Local HTTP.

1. Vor einem Fehlerbericht bestehende Issues durchsuchen.
2. Home-Assistant-Version, Wechselrichtermodell, Firmware, Integrationsversion und Schritte zur Reproduktion angeben.
3. Keine Registrierungscodes, Passwörter, Tokens, privaten Seriennummern oder persönlichen Netzwerkdaten veröffentlichen.
4. Änderungen möglichst klein halten und mit einem nachvollziehbaren Test beschreiben.
5. Pull Requests gegen den Standard-Branch öffnen.

Dieses Projekt ist unabhängig von KACO.
