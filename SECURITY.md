# Sicherheit

Bitte Sicherheitslücken nicht mit sensiblen Zugangsdaten in öffentlichen Issues dokumentieren. Für vertrauliche Meldungen GitHubs **Private vulnerability reporting** in den Repository-Einstellungen aktivieren oder die Maintainer über einen von ihnen veröffentlichten sicheren Kanal kontaktieren.

Die Integration verwendet lokales, unverschlüsseltes HTTP und sollte nur in vertrauenswürdigen Netzwerken eingesetzt werden. Port 8484 nicht öffentlich freigeben.
